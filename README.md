# Учет работы ассистентов

Установимое веб-приложение для учета смен, отработанных часов, выплат и дополнительных расходов.

## Установка на Android

Опубликуйте GitHub Pages из ветки `main` и корня репозитория. Откройте опубликованный HTTPS-адрес в Chrome на Android и выберите в меню браузера «Установить приложение» или «Добавить на главный экран».

Записи хранятся локально в браузере на каждом устройстве отдельно и не отправляются в GitHub. Сам сайт и его исходный код будут общедоступны, если репозиторий открыт.

## Файлы

- `index.html` — учет рабочего времени и расходов.
- `stats.html` — статистика и отчеты за период.
- `app.js`, `stats.js`, `styles.css` — логика и оформление.
- `manifest.json`, `sw.js`, `pwa.js`, `app-icon-*.png` — установка и автономное открытие.
